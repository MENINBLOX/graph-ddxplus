# 연구 설계 T — 진단 지식원의 시간 노후화 (2026-10-13 착수)

> 설계 D(그래프 vs BM25)는 확증에서 T1 미달로 종료(`research_design.md` D9). 이 문서가 현행 설계.

## T0. 목표 (한 문장)
감별진단 지식원(LLM 추출 문헌 그래프, 큐레이션 HPO 주석, PrimeKG)이 자기 시점 이후에 출판된 희귀질환 증례에서
얼마나 빨리, 어떤 모양으로 성능을 잃는지를 같은 증례·같은 시간축·같은 랭커로 측정하고, 그 측정을 계속 갱신 가능한 벤치마크로 공개한다.

## T1. 왜 이 질문인가
- 희귀질환 진단 평가는 단일 스냅샷 벤치마크로 이루어지며, 증례 원문이 큐레이션 지식의 근거로 이미 흡수된 경우가 많다
  (phenopacket-store 0.1.27에서 74.6%, Jiang et al. 2026, arXiv 2609.02473).
- 실제 사용 시점의 환자는 지식원보다 미래에 있다. 회고 평가는 이 간극을 재지 않는다.
- 설계 D 확증에서 0.1.27 이후 증례의 정답 질환 중 59%만 문헌 그래프에 소견이 있었다 — 시간 간극이 성능을 지배할 수 있다는 단서.

## T2. 선행연구와 차별점 (`docs/prior_work_temporal_2026-10.md`)
- LLM의 cutoff 이후 성능 저하: LiveMedBench(2602.10367), TempoMed-Bench(2605.13045) — LLM만, 희귀질환 순위화 아님.
- KG 시간 분할: PrimeKG-CL(2605.10529) — 링크 예측, 진단 아님.
- phenopacket-store 평가: Reese(0.1.14), Jiang(0.1.27) — 단일 스냅샷.
- **빈자리**: 지식원 유형 간 노후화 곡선 비교 + 증례 시점과 질환 등재 시점의 분리 + 출처 누설의 시간적 정의.

## T3. 데이터와 시간축
- 증례: phenopacket-store 0.1.27 + 이후 main(10,776증례, 원 논문 1,834편). 증례 시점 = 원 논문 PubMed 출판일.
- HPO 주석 스냅샷 36개(2022-02 ~ 2026-09, `data/external_kg/hpoa_history/`). 스냅샷 시점 = 릴리스 날짜.
- 문헌 그래프 시점 절단: Mention→Doc.year ≤ Y인 근거만으로 간선을 다시 집계(재추출 불필요 — 문장 단위 출처 덕분).
  증례 원 논문(0.1.27분)은 수집 단계에서 제외됨.
- PrimeKG: 2023-07 단일 시점(대조점).

## T4. 측정
- 증례 나이 = 증례 출판일 − 지식원 시점. 구간: <−3년, −3~−1, −1~0, 0~+1, +1~+2, >+2년.
- 세 층을 분리해 보고: (a) 지식 공백 — 정답 질환이 지식원에 없음, (b) 출처 누설 — 지식원이 그 증례 논문을 근거로 인용,
  (c) 둘 다 아닌 증례의 순위 정확도.
- 지표: lineage Top-1/Top-10(설계 D와 동일), 커버리지.

## T5. 가설
- H1: 모든 지식원은 증례 나이 > 0에서 성능이 떨어진다.
- H2: 큐레이션은 계단형(등재 전 0), 문헌 그래프는 완만한 감소 — 미래 증례에서 문헌이 큐레이션을 앞선다.
- H3: 회고 평가 점수의 상당 부분은 출처 누설에서 온다(누설 제거 시 하락).

- 판정: 신호 충분(H1·H2 방향 일치, 교차점 ≈ 지식원 시점). 미래 구간 표본 수천 건으로 통계 검정 가능.
- 주의: (1) 문헌 커버리지는 소견 1개 이상 기준이라 품질을 보장하지 않음, (2) 코퍼스 수집에 2026년 질환명을 썼으므로
  과거 시점 절단이 당시 검색 가능성을 과대평가할 수 있음, (3) 오래된 증례일수록 잘 알려진 질환이라 질환 난이도가 교란 —
  같은 질환 내 비교(질환 고정효과)로 통제할 것.

## T7. 다음 단계
1. 문헌 그래프 시점 절단 랭킹(같은 1-홉 랭커, 연도별 그래프를 7688에 구축).
2. HPOA 스냅샷도 같은 Neo4j 랭커로 재측정(사전테스트 간이 랭커 교체).
3. 질환 고정효과 분석, 누설 정의 고정.
4. LLM 축은 사용자 허락 후(학습 마감 전후 비교).

## T8. 본 측정 결과 (2026-10-14, 설계 D 동결 설정, 랭커 = Neo4j 1-홉, `pilot/cache/v2/temporal/analysis.json`)
대상 10,603증례(0.1.27 + 신규 main, 정답·소견 매핑 가능분). 문헌 그래프 2019~2025 연말 절단 7개, HPOA 6개 스냅샷, 로컬 LLM 8개(공개일 = 학습 마감 상한).

**1. 사전테스트의 교차(H2)는 정확도에서 재현되지 않음.** 미래 증례 @10: HPOA 16.5 / 11.0(+2년 초과) vs 문헌 10.8 / 6.7.
일치 시점 대응 비교에서 미래 증례도 HPOA 우세(문헌−HPOA @10 −3.5 ~ −8.9, 모두 CI가 0 미포함). 커버리지 우위가 순위 정확도로 이어지지 않음.

**2. 출처 누설(H3) 확인.** 과거 증례에서 HPOA가 그 증례 논문을 이미 인용: @10 81.7(n=22,426), 미인용 41.1(n=30,036).
관행 평가(0.1.27 + 최신 HPOA 2026-09) @10 77.4 vs 시간 분할 미래 증례 16.5.

**3. 같은 질환 안에서의 감소(질환 난이도 통제).** 질환×스냅샷 쌍 단위 과거→미래 @10:
HPOA −9.6 [−12.5, −6.7], 문헌 +0.3 [−1.0, +1.5], LLM 8개 모두 유의한 감소 없음(−6.2 ~ +4.7, 대부분 CI 0 포함; 쌍 수 10~63).
→ 문헌 그래프·LLM의 연도별 하락은 질환 구성 변화(교란)이고, HPOA만 고유한 시간 감소(누설 소멸)를 보임.

**4. 질환 등재 여부가 지배.** 스냅샷 시점에 HPOA에 아직 없던 질환(첫 등재 > 스냅샷, 2022-02 이후 스냅샷만):
미래 증례 @10 HPOA 0.1, 문헌 0.7(대응 n=4,812: 0.69 vs 0.06), LLM 8개 모두 0.0. 이미 등재된 질환은 미래 증례에서도 HPOA 45.8, 문헌 28.4, LLM 7~24.
→ 모든 지식원 유형이 "아직 큐레이션되지 않은 질환"에서 사실상 0. LLM도 큐레이션된 질환만 맞힘.

**5. 연도별 LLM 정확도의 불연속은 다환자 논문 군집 때문.** 2018년 NF1 157증례(쉬움), 2019년 OMIM:612313 157증례(어려움) —
증례 단위 연도 곡선은 해석 불가, 질환 단위 매크로·질환 고정 비교가 필요.

**판정**: H1(모든 지식원 감소)은 질환 구성 교란을 통제하면 HPOA에만 성립. H2 기각. H3 강하게 지지.
주 기여 후보 = phenopacket-store 회고 평가의 과대평가를 누설·지식 공백·질환 구성으로 분해하는 시간 분할 평가 프로토콜.
문헌 그래프의 고유 우위는 신규 질환에서 0.6%p 수준으로 실질적 의미 없음.
제약: LLM은 4~14B 로컬 모델만(최상위 API 모델 미포함), HPOA 기반 공개 도구(Exomiser·Phenomizer)는 1-홉 랭커로 근사.
