**용어**
- **evidence** — DDXPlus에서 증상(symptom)과 병력(antecedent)을 함께 부르는 말이다. 질문 하나는 evidence 코드 하나다.
- **양성(present)** — 이진 evidence는 기록되어 있으면 양성이다. 범주형·다중선택은 `default_value`가 아닌 값이 기록되어 있을 때만 양성이다. 공식 코드(`code/basd/env.py:253-300`, `parse_target_patients`)와 같은 정의다.
- **기록 기준** — 값과 무관하게 코드가 `EVIDENCES`에 있기만 하면 '있음'으로 보는 해석이다. §4.3에서 보듯 이 해석은 정답 질환의 목록을 누설한다.
- **공개 목록** — `release_conditions.json`에서 한 질환의 `symptoms`와 `antecedents`를 합친 목록이다.
- **지지집합(support)** — 생성기가 한 질환에서 실제로 양성으로 만들 수 있는 evidence의 집합이다. 집합론의 support(0이 아닌 확률을 갖는 원소들)에서 온 말이다.
- **암묵 응답(implicit evidence)** — 묻지 않은 하위 질문의 답을 부모 질문의 답으로 채우는 것이다. CASANDE 코드의 `implicit_symptoms`에서 따온 이름이다.
- **Diff ✓ / ✗ 행** — 문헌 표에서 감별진단 분포를 목표로 학습한 모델은 ✓, 정답 질환을 목표로 학습한 모델은 ✗로 표시한다.

## 1. 결론

지적이 맞다. 현재 설계(`docs/design/ddxplus_kb_redo.md`)는 DDXPlus의 데이터 구성을 확인하지 않은 전제 위에 몇 가지 결정을 세웠다.

- **"환자는 공개 지식 파일로 생성되었다"는 전제(설계 L10, L14)는 사실이 아니다.**
  - 실제 생성에는 세 가지가 쓰였다. 나이·성별에 조건부인 확률을 가진 비공개 KB, Synthea, 그리고 감별진단을 만든 상용 규칙 기반 시스템이다.
  - 공개 파일은 확률이 모두 지워진 소속 목록이다. 값이 전부 `{}`다.
  - 관측된 관계는 두 가지다. 양성 evidence는 모두 목록 안에 있다(위반 0건). 그러나 목록 888항목 중 46개는 train 1,025,602명에서 한 번도 양성이 아니다.
- **설계가 "표준 프로토콜"이라고 적은 것은 공식 프로토콜이 아니다.**
  - 설계: 초기 evidence 1개, 초기 evidence 포함 |T| ≤ 30.
  - 공식: 나이·성별·초기 evidence를 함께 주고, 초기 evidence 외에 30문항까지 묻는다. 따라서 IL은 최대 31이다.
- **평가 세트 구성의 근거가 약하다.**
  - H1(공식 test − 9,000)은 노출을 없애지 못한다. 공식 test 전체가 이전 판(v1)의 개발에 쓰였기 때문이다. 그러면서 문헌과 평가 행만 달라진다.
  - H2(train에서 뽑은 hold-out)는 test와 질환 분포가 다르다(χ² 974, df 48). 문헌의 방법들이 학습에 쓴 행이기도 하다.
- **BED와의 대조(J3)는 비교 대상을 잘못 골랐다.** BED는 나이·성별을 쓰지 않고 train 전체로 빈도를 셌다. 그런데 J3은 나이·성별을 쓰고 train − H2로 빈도를 센 판과 비교했다.
- **하위 질문 계층, PER, GTPA@1의 동점 처리를 어느 공식 구현에 맞출지 정하지 않았다.**

반면 측정의 핵심은 데이터와 공식 코드에 맞는다.
- 기본값 = 음성
- 질문 단위 = evidence 코드 1개
- IL에 초기 evidence를 포함
- 목록 밖 양성 0건
- 집합 포함 유일성 92.35%

1차 평가(동결 `a06db1e`)의 P1 결과는 validation 98.34%, H1 98.37%, H2 98.39%였다. 이 결과의 방향을 바꿀 결함은 찾지 못했다. 다만 영향의 크기는 다시 실행하기 전까지 미확인이다.

권장 절차는 다음과 같다.
1. 1차 결과를 그대로 보존한다.
2. 공식 문서·코드에서 바로 정해지는 수정만 담은 보완판을 평가 전에 커밋한다.
3. 공식 test 전체(134,529명)에서 한 번 더 평가한다.
4. 두 결과를 모두 보고한다.

이 재평가는 결과를 이미 본 뒤의 실행이므로 "독립 확증"이라고 부르지 않는다.

## 2. DDXPlus는 어떻게 만들어졌나

### 2.1 생성 과정 (DDXPlus 논문 arXiv 2205.09148 v3 §3, 부록 A–E; zip 안 `README.md`)

**두 단계로 만들었다**(p.3).
1. 비공개 의료 KB, 뉴욕주 인구조사(2010–2015), Synthea로 환자의 인구학 정보, 질환, evidence를 합성했다.
2. 상용 규칙 기반 진단 시스템(DXA)으로 그 환자의 감별진단(`DIFFERENTIAL_DIAGNOSIS`)을 만들었다.

KB와 DXA는 Dialogue Health Technologies가 제공했다(각주 2).

**비공개 KB**
- 규모는 440개 질환, 802개 evidence다. 이 가운데 기침·인후통·호흡 문제를 주소로 하는 49개 질환과 223개 evidence(증상 110, 병력 113)만 쓰였다.
- KB에는 확률이 있다: "a set of symptoms and antecedents … together with their related probabilities. These probabilities are conditioned on the age and sex of the patient"(p.4).

**생성 규칙**
- 식 (1)–(3): p(age,sex,geo)·p(d|age,sex,geo)·p(E|d,age,sex). evidence는 질환·나이·성별이 주어지면 독립이다(KB가 따로 정한 경우는 예외).
- 질환 사전확률은 incidence로 정하되, 10–100% 범위로 자른다.
- 여행 확률 p(travel) = 0.25, 목적지는 균등이다.
- 정수형 값은 KB 평균 v를 중심으로 [v−3, v+3]에서 균등하게 뽑는다.
- 범주형·다중선택은 조건부확률이 **낮은 값부터** 차례로 켠다. 범주형은 1개, 다중선택은 5개가 켜지면 멈춘다. 그래서 관측 빈도는 KB 확률과 같지 않다.

**초기 evidence**
- README와 p.22는 "randomly selected from the binary evidences found in the evidence list"라고 적었다.
- 실측(§4.5)으로는 **양성 이진 증상 가운데 균등 추출**이다. 병력이 초기 evidence인 경우는 0건이다.

**감별진단 라벨**
- DXA에는 나이, 성별, 주소를 넣었다. 그다음 환자의 evidence 전부를 한 번에 주고, 추가 질문에는 "no"로 답했다.
- 다음 환자는 버렸다: 생성기 내부 상한 30에 닿은 환자, DD에 시뮬레이션 질환이 빠진 환자.
- 49개 밖의 질환은 DD에서 지우고 확률을 다시 정규화했다. 평균 1.78개, 질량 0.10이 지워졌다.
- 결론 p.10은 이렇게 적었다: "we guarantee that the differentials are informed by all relevant positive evidences … not guaranteed that all relevant negative evidences … are considered."

### 2.4 분할

- **논문 §3.4**: "80%-10%-10% split, using stratified sampling on the simulated pathology."
- **실측 행 수**: train 1,025,602 / validate 132,448 / test 134,529행이다. 비율은 79.35 / 10.25 / 10.41%다.
- **층화로 보기 어렵다.**
  - 질환별 validate/train 비가 0.061–0.142로 벌어진다. 예: Laryngospasm은 기대 약 1,420행인데 관측은 668행이다.
  - 분할 간 질환 분포의 χ²(df 48): validate 대 train 1,363.7, test 대 train 974.0, test 대 validate 175.4.
  - 실제 분할 절차는 공개되지 않았다(**미확인**).
- **공식 용도**: train은 학습, validate는 하이퍼파라미터 조정, test는 보고에 쓴다. 근거는 DDXPlus p.9, CASANDE p.7, BASD readme다.

## 3. 공식 상호작용 프로토콜과 문헌의 실제 사용

### 3.1 논문 문장

- DDXPlus §4.2: "Each patient provides their **age, sex, and an initial evidence** … The model then iteratively inquires about a symptom or an antecedent … We use **T = 30** in all experiments."
- CASANDE(arXiv 2210.07198) p.4: 행동은 evidence E개와 종료 1개다. "only actions not yet selected in the episode are available."

### 3.2 공식 구현 세 가지 (코드 확인)

| 항목 | DDXPlus 기준선 BASD·AARLC (`mila-iqia/ddxplus/code`) | CASANDE (`Casande-RL/chloe`) | BED (`Casande-RL/Baselines/BED`) |
|---|---|---|---|
| 시작 입력 | 나이 8구간 + 성별 + `INITIAL_EVIDENCE` (`basd/env.py:854-890`) | 같음. 나이 구간 [0,1), 1–4, 5–14, 15–29, 30–44, 45–59, 60–74, 75+ (`simulator.py:_set_demo_features`) | **초기 evidence만.** 나이·성별을 쓰지 않는다 (`bayesian_experimental_design_batch.py:226`) |
| 한 턴 | evidence 코드 1개 | evidence 1개 또는 종료. 이미 고른 것은 가린다 | 효용이 최대인 evidence 1개 |
| C/M 응답 | 환자 값을 모두 공개한다. 미기록이면 기본값 | 같음 (`simulator.py:2010-2060`) | 같음 |
| 하위 질문 계층 | **전파 없음.** 물은 것만 채운다 (`basd/env.py:394-407`). 자식을 먼저 물어도 된다(논문 부록 K의 실제 예) | **암묵 응답 전파.** 부모가 '없음'이면 자식을 기본값으로 채우고, 자식이 양성이면 부모를 '있음'으로 채운다. 턴을 쓰지 않는다 (`simulator.py:1917-1965`) | 전파 없음 |
| 질문 상한 | 초기 외 30문항 (`basd/dataset.py:468,634`, AARLC `--MAXSTEP 30`) | 같음 (`batchEvaluator.py:91`) | `for step in range(30)` |
| IL | `sum(valid_timesteps)+1` → **최대 31**, 초기 포함 (`basd/metrics.py:146`) | 같음 (`chloe/evaluator/metrics.py:271`)* | `len(all_diags)` = 1 + 질문 수 |
| 지식 | train으로 학습 | train으로 학습 | **train 전체의 빈도**: P(d)=`value_counts`, 미관측 값은 1e-7, 초기 evidence를 가진 질환으로 후보 제한 (`ddxplus_utils.py:96`, `data_utils.py:157`, `:230`) |
| 종료 | BASD는 확률 임계 0.5, AARLC는 엔트로피 임계 | 종료 행동 또는 30 | 효용 < 0.01 |

\* 문헌 검토는 CASANDE IL을 다른 위치(`len(all_proba_dist)`)에서 보고 초기 포함 여부를 미확인으로 남겼다. 원고에 인용하기 전에 한 번 더 대조한다.

### 3.3 지표의 코드 정의

- **0.01 후처리**: 예측 감별진단과 정답 감별진단 모두에서 질량 ≤ 0.01인 질환을 지운다(p.9, 부록 H).
- **GTPA@1** (`basd/metrics.py:151`, `chloe/evaluator/metrics.py:276`): `disease == argsort(pred)[::-1][0] AND pred[disease] > 0.01`. 동점 규칙은 따로 없고 numpy `argsort` 결과를 그대로 쓴다.
- **PER**: inquired 집합에 **초기 evidence가 들어간다**(`basd/env.py:374`, BED도 같다). 분자와 분모 모두에 포함된다.
- **DDR·DDP·DDF1**: 환자별로 계산해 평균한다. DDF1은 환자별 F1의 평균이다.
- **DSHM**: CASANDE의 지표로, 중증(severity < 3) 질환의 rule-in·rule-out 조화평균이다.
- **GTPA@1의 쓰임**(p.9): "only relevant for models trained to predict the ground truth pathology." 저자는 감별진단을 학습 목표로 쓰라고 권한다(issue #3).

### 3.4 문헌 보고값 (공식 test, 3회 평균. BED만 1회)

### 4.1 질환 분포와 분할 차이

- **불균형(최다/최소)**: train 246.6배(URTI 64,368 / Bronchiolitis 261), validate 309.1배, test 242.9배다. Bronchiolitis는 validate 28명, test 36명뿐이다.

  - Whooping cough 0.592 / 0.411 / 0.408
- **train 끝의 정렬된 66,248행**(행 959,354–1,025,601)
  - 질환별 연속 블록 49개이고, 블록 순서는 프랑스어 질환명 정렬순이다.

### 4.3 기본값 기록 규칙과 하위 질문 계층

- **목록에 있는 비이진 evidence는 그 질환 환자 전원에게 기록된다.** 양성이 아니면 기본값으로 기록된다. 목록에 없으면 한 명에게도 기록되지 않는다. 1.16M행에서 예외가 0건이다.
  - 그래서 **기록 기준으로 읽으면 정답 질환의 목록이 드러난다.** 예: Sarcoidosis 환자는 100%가 기본값으로 기록된 피부병변 하위 코드를 갖는다.
  - `trav1`은 전원에게 기록된다. 값이 `N`인 비율은 92.2%(validate)다.
- **부모 없이 자식만 기록된 행**: 이때 자식 값은 항상 기본값이다.
  - train: 통증 10,859(1.06%), 피부병변 32,609(3.18%), 부종 12,376(1.21%)
  - validate: 1,289 / 4,575 / 1,542
- **부모가 있으면 목록에 있는 자식은 모두 기록된다.** 기본값일 수도 있다. 예: 통증 환자 788,079명 중 581,387명은 `douleurxx_irrad`가 `nulle_part`다.
- **목록상 계층이 불완전한 경우**
  - SLE 목록에는 `lesions_peau_intens`가 빠져 있다.
  - `oedeme`는 8개 질환의 목록에 있지만 자식은 5개 질환에만 있다.
- **다중선택 값의 수**: `douleurxx_carac`는 값이 최대 7개다(train 6,367행). 논문의 "limit to 5"와 다르다.

### 4.4 초기 evidence

- train·validate 1,158,050행 모두에서 초기 evidence는 **이진·증상·루트 코드**이고, 질환의 목록 안에 있다. 병력이나 하위 질문이었던 적은 0번이다.
- 96개 이진 증상이 모두 초기 evidence로 등장한다.
  - 상위: `douleurxx` 18.4%, `dyspn` 8.4%, `toux` 7.4%
  - 분포는 환자의 양성 이진 증상 가운데 균등 추출과 일치한다(χ² 59.5–66.8, 자유도 약 93–95).
- 초기 evidence를 목록에 가진 질환 수는 평균 14.3, 중앙 8, 범위 1–34다(validate).

### 4.5 나이·성별

생성기의 나이 제약이 뚜렷하다(train 최소–최대). 이 정보는 **공개 KB 파일에 없다**.
- Bronchiolitis 0–1세, Croup 0–9세
- 협심증 2종, NSTEMI·STEMI, 폐부종, 췌장 신생물 ≥18세

성별만으로 배제되는 질환은 없다. 성별 특이 evidence(`preg1` 등)는 여성에게만 나온다.

### 4.6 DIFFERENTIAL_DIAGNOSIS (정답 감별진단)

- **길이**: 1–34, 평균 9.18.
- **정답 질환과의 관계**
  - 정답 질환은 항상 DD 안에 있다.
  - DD 1위 = 정답인 행: validate 73.37%, train 73.68%.
  - 1위 동점: validate 261행.
  - 0.01 후처리로 정답 질환이 정답 DD에서 빠지는 행: validate 197행.
- **공개 KB와 맞지 않는다**(validate)
  - DD 질량의 평균 70.1%(중앙 80.1%)가 목록상 배제되는 질환에 있다.
  - 77.3%의 행은 초기 evidence조차 목록에 없는 질환을 DD에 포함한다.
  - 정답이 아닌 DD 구성원 가운데 환자의 양성 evidence를 모두 덮는 질환은 0.79%뿐이다.
- **해석**: DD는 상용 시스템의 출력이다. 공개 목록으로 재현할 수 있는 목표가 아니다.

"정확 중복"은 (나이, 성별, 질환, 초기 evidence, evidence 항목 집합)이 모두 같은 행이다.

### D5. H2의 필요성

- **설계 근거**: "이전 판이 test를 개발에 썼으므로, 개발에 쓰지 않은 추가 평가 세트를 둔다."
- **데이터 구성상 문제**
  1. **추정 대상이 다르다.** H2는 train에서 무작위로 뽑았다. 질환 분포가 train이고, test와 χ² 974(df 48)만큼 다르다. P1은 균등 사전확률이라 집계 정확도의 가중만 달라진다. P2는 train − H2의 사전확률이 H2와 같은 분포에서 오므로 H2에서 유리하다.
  2. **문헌과 비교할 수 없다.** 문헌의 방법은 이 행들로 학습했다.
  3. **완전한 미사용 세트도 아니다.** 원고 한계 절에 따르면 이전 분석이 train 앞 200k–300k행과 train 전체로 빈도·동시출현을 집계했다. 여기에 H2 행 26,284–39,427개가 들어갔다.
  4. **1차 평가로 열렸다.** 재설계 뒤에는 어떤 분할도 미열람 상태가 아니다.
  5. train − H2와의 정확 중복이 2.15%로 test(1.48%)보다 높다. P1에는 무관하고, P2에는 미미하다.
- **판단**
  - P1은 환자 데이터로 아무것도 학습하지 않는다. 고른 하이퍼파라미터도 3개(27개 후보)다. 데이터는 i.i.d. 합성이고 n이 13만이다.
  - 그래서 "test에 맞춘 과적합"의 위험은 원래 작았다. 1차 결과(validation 98.34 / H1 98.37 / H2 98.39)가 이를 보여 준다.
  - H2가 준 증거는 이미 1차 평가에서 다 썼다.
- **수정**
  - 재설계의 판정 세트에서 H2를 뺀다.
  - 1차 H2 결과는 "봉인 세트에서 한 번 평가한 결과"로 부록에 그대로 둔다.
  - P2 빈도는 train 전체로 센다(D6).
  - H2를 연속성 확인용으로 다시 돌린다면 "2회차 열람"이라고 표시한다. 질환별 정확도와 test 사전분포로 재가중한 값을 함께 낸다.

### D11. J3(BED 대조)

- **설계**: P2(값 단위 + 나이·성별, train − H2)의 H1 결과를 BED 보고값(99.47%, IL 5.47)과 비교했다. 허용은 GTPA@1 ±1.0%p, IL ±1.5다.
- **BED 코드의 실제 동작**
  - 나이·성별을 쓰지 않는다.
  - P(d)와 우도는 train 전체의 빈도다. 미관측 값은 1e-7이고, Laplace 평활은 없다.
  - 초기 evidence를 가진 질환으로 후보를 제한한다.
  - 효용이 0.01 미만이면 멈춘다. 질문은 30개까지다.
  - 평가는 공식 test 전체에서 1회 했다.
- **문제**
  - 비교한 판이 BED와 다른 입력을 쓴다.
  - IL ±1.5는 BED IL의 27%라 판정력이 없다.
  - 원고는 "BED의 IL 정의와 빈도 추정 split은 확인하지 못했다"(L121)고 썼는데, 이제 둘 다 확인되었다.
- **수정**
  - BED 규칙을 그대로 옮긴 재현(B-BED)을 같은 하네스에서 공식 test 전체로 돌린다. 가능하면 원 코드(`Casande-RL@5279013`)도 함께 돌린다.
  - 재현 차이를 보고하고, P1·P2를 B-BED와 같은 행에서 짝비교한다.
  - 후보 제한이 KB 목록 기준인지 train 빈도 기준인지는 **미확인**이다. 코드를 읽어 확정한다.
- **1차 결과를 사후에 읽으면**
  - 나이·성별을 쓰지 않는 P2 값 단위 판의 H1 결과는 99.54%, IL 6.08이다(설계 문서 결과표). BED와의 차이는 +0.07%p, +0.61이다.
  - 이것은 사전에 정한 비교가 아니므로, 쓴다면 "사후 대조"라고 표시한다.

- 1차 평가의 환자별 출력에 사후 벡터가 저장되었는지(열지 않음).
- COTCAgent·CaRDI·MedExAgent의 표본 추출과 응답 처리. 요약 도구를 거쳐 읽었으므로 원문 대조가 필요하다.
- 웹 검색에 노출된 `github.com/MENINBLOX/graph-ddxplus` 저장소가 공개 상태인지, 그 내용이 무엇인지. 원고의 공개 문단에 반영할지 판단해야 한다.
